# Resúmenes de instituto

Repositorio con los resúmenes HTML de los temas de instituto y una página central de acceso.

## Estructura

- `index.html`: página central con enlaces a todos los temas.
- `temas/electricidad.html`: resumen de electricidad y componentes pasivos.
- `temas/tema4-instalaciones-telefonia.html`: resumen del Tema 4 de instalaciones de telefonía.
- `temas/guia-telefonia.html`: guía interactiva de telefonía.
- `styles.css`: estilo común de las páginas de resumen.
